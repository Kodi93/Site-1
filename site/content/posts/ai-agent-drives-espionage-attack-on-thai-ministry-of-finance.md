Attackers used Hermes, an autonomous open source tool, in unrestricted "YOLO mode" to conduct espionage against Thailand's Ministry of Finance. July 28, 2026 Threat actors targeting Thailand's Ministry of Finance (MOF) used an autonomous AI agent to carry out portions of an apparent cyber-espionage operation. Threat intelligence Hunt.io on July 23 detailed the incident via a research blog post. Although espionage — while newsworthy — is not necessarily an unusual occurrence in its own right, this attack stands out because the attacker was supported by an autonomous AI agent via an open source tool named Hermes . From July 9 to 13, Hunt.io's platform Attack Capture identified three simultaneous open directories hosted in Hong Kong, which contained exploit code for multiple CVEs, Web shells, suo5 HTTP tunnels, and custom scripts. Hunt.io discovered that the attack, targeting the Thai MOF, was largely driven by the Hermes Agent in the unrestricted "YOLO" mode, a capability allowing the agent to function without human approval. This is the latest example of attackers offloading a significant portion of their threat operations onto large language models (LLMs). Earlier this month, security and incident response firm Sygnia detailed how a lone attacker used AI to orchestrate a complex campaign against a large Amazon Web Services (AWS) customer environment, ultimately leading to a successful extortion. Related: Brazilian Banking Trojan Actively Spreading in Portugal The Thai government has not commented on the attack, but Hunt.io noted they and fellow security researcher Bob Diachenko reported the attack to Thailand's national CERT and National Cyber Security Agency (NCSA) on July 15. The government acknowledged receipt on the same day, and publication "was held for the standard 7-day disclosure window," according to Hunti.io. Although Hunt.io was unable to determine the exact means of initial access, the attacker infrastructure had extensive post-exploitation tooling, such as the aforementioned Web shells as well as staged privilege-escalation exploit code targeting both Linux and Windows. As researchers put it, the files in the identified attack infrastructure "describe an intrusion still running," with tooling staged and internal access expanding. "Purpose-built scripts target MOF Hadoop infrastructure with a HiveServer2 client using hardcoded credentials and a malicious Hive UDF issuing commands and returning output over WebHDFS," the blog post read. Among the infrastructure in the environment, researchers identified "Hades" — a malware custom Windows and Linux implant written in Go and hosted alongside ministry-specific reconnaissance, exploitation, and credential-access tooling. Although the research did not specify exactly where Hades was deployed in the MOF environment, its core capabilities included interactive remote shell access, persistence tasks, in-memory execution, file transferring, and SOCKS proxying — a technique that turns a compromised machine into a relay point for network traffic . Related: Ransomware Attack Puts a Chill on Japanese Frozen-Food Chain Hermes was used to support these aforementioned capabilities. Threat actors used it to perform system enumeration, escalate privileges, discover files and services, and conduct network reconnaissance. Researchers also noted Hermes "made use of the open-source project LinPEAS (Linux Privilege Escalation Awesome Script) to further move through the network." "Additional logs indicate the operator instructed the agent to enumerate a content directory containing PDF, DOC, XLS files, and personnel records associated with the Office of Permanent Secretary for Finance. There is no evidence the files were exfiltrated," Hunt.io wrote. Esteban Borges, head of research at Hunt.io, tells Dark Reading the firm found no evidence that data of any kind was exfiltrated from the ministry environment. Because the identified attacker infrastructure was previously used as a ShadowPad controller (ShadowPad malware has been associated with Chinese state espionage groups ), Hong Kong-based infrastructure, and multiple Chinese-language indicators, Hunt.io made "a low-to-medium confidence assessment that the actor behind this activity is Chinese-speaking or intimately familiar with the language." Related: Ransomware Thugs Masquerade as Interpol to Entice Small Biz Hunt.io recommended defenders review the HiveServer2 authentication mode, as its default "accepts any credentials passed over SASL PLAIN without validating them, and the operator's script was written to rely on exactly that"; enforce the HiveServer2 UDF blocklist; audit Web roots recursively for PHP files similar to those the attacker used; and patch sudo and polkit so that they're protected against exploits used by the attacker. Other recommendations, as well as indications of compromise, are available in the blog post. This isn't the first attack of its kind Hunt.io has identified. Two weeks ago, Hunt.io detailed a campaign in which suspected Chinese operators used Claude Code and DeepSeek to target financial systems across four different countries . Borges notes a pattern of these AI-powered attackers having poor operational security. The Thai attack came apart because three directories were exposed, and the early attack was exposed because infrastructure was left as an open directory anyone could browse. "Both times the automation generated a large volume of records, and both times the operators didn't lock it down. The same tooling that speeds these operations up also produces a paper trail, and if it's left exposed it becomes a direct window into how the intrusion ran," he says. "Whether that actually makes them easier to catch, I don't know yet, but so far the AI-heavy operations have left more behind, not less."
