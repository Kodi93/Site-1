As Microsoft explained when it acknowledged the issue last month, affected users experienced multiple symptoms, most commonly a black screen after sign-in, being unable to access their desktop until they manually started the desktop session, and Windows Explorer crashes in application event logs. However, this known issue mainly affects Azure Virtual Desktop (AVD) hosts using FSLogix , a software solution that speeds up user profile loading in virtual desktop environments. Microsoft has now addressed the bug in cumulative updates released as part of this month's Patch Tuesday and asked affected users to update their systems. "This issue was resolved by Windows updates released October 13, 2026 [..] and updates released after that date. We recommend you install the latest update for your device as it contains important improvements and issue resolutions, including this one," it said in a release health dashboard update. "If you install an update released October 13, 2026 [..] or later, you do not need to use a workaround for this issue." Microsoft shared a temporary workaround for those who can't install this month's Windows updates, which requires them to manually launch Windows Explorer. This can be done by opening Task Manager (Ctrl+Shift+Esc), selecting Run new task , entering explorer.exe , and clicking OK . It also mitigated the issue for enterprise customers via Known Issue Rollback (KIR), which has to be applied on enterprise-managed devices by installing one of the following group policies: "You will need to install and configure the Group Policy for your version of Windows to resolve this issue. You will also need to restart your device(s) to apply the group policy setting," Microsoft noted . "Note that this Group Policy will disable the change causing this issue until a resolution is released in a future Windows update. IT admins can find further details on deploying and configuring KIR group policies on Microsoft's support website .
